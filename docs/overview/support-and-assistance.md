# 支持和帮助

您可以通过WAGO SCADA [支持中心](https://forum.wagoscada.cn/) 获取各种帮助。我们首先推荐您使用的是 [用户手册](https://www.wagoscada.cn/support-center/usermanual)，该手册包含您需要了解的WAGO SCADA的各个方面。当然我们也提供交互式的 [在线论坛](http://forum.wagoscada.cn/)，您可以随时通过在论坛留言获取WAGO官方或者其他热心用户的帮助。您也可以通过浏览 [常见问题](https://www.wagoscada.cn/support-center/training#faqs) 来快速找到解决方案。当然如果您是付费用户，您可以随时通过我们的 [工单系统](https://www.wagoscada.cn/support-page?wpsc-section=ticket-list)，向我们提交您遇到的问题。

#### 长期支持版本

我们长期以及持续致力于改善我们的WAGO SCADA产品，包括诸如功能的新增和改进，性能和稳定性的提升，兼容性的保证等。所以我们提供长期支持版本（LTS，Long-Term Support），此类版本提供5年的问题支持，WAGO SCADA将在支持期限内，持续进行版本的问题修复。您可以从我们的 [支持政策](https://www.wagoscada.cn/support-center/technology-support) 中，详细了解这些内容。

#### 反馈和评论

我们也欢迎您对WAGO SCADA的各个方面提出反馈或者评论，我们将认真阅读和考虑您的宝贵意见和建议，并在接下来的工作中加以改进。除了WAGO SCADA本身，您也可以对我们的用户手册、论坛等一切相关资源进行反馈和评论。最直接的方式是您可以在我们的 [在线论坛](https://forum.wagoscada.cn/) 进行反馈，当然您也可以通过邮箱联系我们进行反馈。
