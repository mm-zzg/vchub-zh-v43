# Features

**描述：此项目用于介绍 WAGO SCADA 的各种核心功能。**

您可以点击该项目的“设计”按钮，在编辑器中点击“打开画面”，查看各个画面。

![alt text](23.png)

### Binding

介绍WAGO SCADA的4种属性绑定。在Home项目的运行页面上，点击Binding图标，显示的即为此画面。

![alt text](24.png)

### Alarm

介绍WAGO SCADA的报警功能。在Home项目的运行页面上，点击Alarm图标，显示的即为此画面。
